# Proyecto JC (React + Vite)

```bash
npm install
npm run dev      # servidor de desarrollo
npm run build    # build de producción en /dist
```

Estructura: `src/components/` (Header, Hero, About, Services, ServiceCard, Projects, Contact, BackToTop, Footer), `src/data/content.js` (textos y listas), `src/styles.css`, `src/assets/img/`.
